## About the course

Official courseware for **AI Vibe Coding for Excel VBA** (**C357**), conducted by
**Tertiary Infotech Academy Pte Ltd** (UEN 201200696W).

The course combines practical Excel automation with an evidence-based AI coding workflow.
Learners use AI to generate and refine VBA, but remain responsible for reviewing the code,
testing it in the supplied workbook and recording evidence that the result meets each lab's
acceptance criteria. Every lab follows the same six-stage loop:

```text
Frame the task -> Prompt the AI -> Inspect the VBA -> Run safely
        ^                                              |
        |                                              v
Record evidence <- Refine the prompt and code <- Test the result
```

All 31 labs build one connected deliverable: the **NorthWind Sales Commission Tracker**, an
automated commission workbook for a Singapore office-furniture distributor. Learners finish with
a working tool that captures sales through a validated UserForm, applies banded commission,
handles errors and produces a chart.

## Getting started

Prerequisites: Microsoft Excel 2016 or later, or Microsoft 365, on Windows or Mac. No prior
programming experience is required, but basic familiarity with formulas and worksheets is useful.

1. Download or clone this repository.
2. Open the relevant `lab-NN-start.xlsm` and select **Enable Content** only after confirming the file source.
3. Read the lab's AI prompt, review checklist and acceptance test before generating code.
4. Inspect the AI-generated VBA, then test it on the supplied mock data.
5. Compare the verified result with `lab-NN-end.xlsm` and the source in `vba/`.
6. Save only as `.xlsm` — saving as `.xlsx` discards the VBA project.

Guardrails: never send confidential data to a public AI tool, never run code you do not
understand, and verify the final output independently.
