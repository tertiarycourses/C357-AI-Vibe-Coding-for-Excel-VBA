## How to use these files

1. Open **lab-01-start.xlsm**. (Click **Enable Content** on the yellow security bar if Excel shows one.)
2. Follow the steps in [the lab](lab-01-set-up-the-developer-ribbon-and-save-a-macro-enabled-workbook.md), typing the code yourself — that is the skill this course builds.
3. Generate and review your own code first. The **end workbook already contains the runnable worked solution**; the matching files in `vba/` are available for inspection or recovery.
4. Compare your result with **lab-01-end.xlsm**.
5. Save your work as **.xlsm** — saving as .xlsx discards every macro.
